# KusteAI

Простой персональный ИИ-ассистент **KusteAI** с:

- доступом в интернет (через DuckDuckGo Search);
- использованием готовой LLM через OpenAI-совместимый API (можно бесплатные сервисы);
- долговременной памятью в SQLite (запоминает диалог и факты);
- CLI-режимом (можно быстро запустить на любом сервере/ПК).

## Что это решает

По вашему запросу: ассистент с именем KusteAI, который умеет искать в интернете, учиться на ваших сообщениях и запоминать информацию в бесплатном хранилище.

- **Готовый ИИ**: подключается к внешней модели (например, OpenRouter, Groq, Together, локальный сервер и т.д.).
- **Обучение на диалоге**: сохраняет важные фразы пользователя в память.
- **Память**: бесплатная локальная SQLite-база (`kusteai.db`).

## Быстрый старт

### 1) Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 2) Настройка окружения

Скопируйте пример:

```bash
cp .env.example .env
```

Заполните `.env`:

- `KUSTEAI_API_KEY` — ключ провайдера;
- `KUSTEAI_BASE_URL` — OpenAI-совместимый endpoint;
- `KUSTEAI_MODEL` — имя модели;
- `KUSTEAI_OWNER_NAME` — ваше имя/логин, для персонализации.

### 3) Запуск

```bash
python main.py
```

---

## Поддерживаемые команды в чате

- обычный текст — диалог с ИИ;
- `/search ваш запрос` — интернет-поиск;
- `/remember текст` — явно сохранить факт в память;
- `/memories` — показать последние факты;
- `/exit` — выйти.

---

## Пример бесплатных провайдеров

> Важно: бесплатные тарифы меняются. Проверьте актуальные условия.

- OpenRouter (есть free-модели);
- Groq (часто есть бесплатные лимиты);
- локальный OpenAI-compatible gateway (например, через Ollama + proxy).

---

## Архитектура

- `main.py` — CLI-точка входа;
- `kusteai/agent.py` — логика ассистента;
- `kusteai/llm_client.py` — клиент LLM;
- `kusteai/search.py` — интернет-поиск;
- `kusteai/memory.py` — долговременная память (SQLite);
- `kusteai/config.py` — загрузка настроек.
